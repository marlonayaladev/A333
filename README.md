# Asset Example

A simple React Native example demonstrating how to use local assets and components.

## Structure

```
├── assets/
│   └── snack-icon.png
├── components/
│   └── AssetExample.js
├── App.js
├── package.json
└── README.md
```

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npx expo start
   ```

3. Scan the QR code with your phone or run in an emulator.
